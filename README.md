# Rust CLI TODO TRACKER

I've been learning Rust for two weeks now and have mastered it quite well. This project was the first time I've used crossterm. This tracker is completely FOSS.

## HOW TO USE

Make sure you have Cargo with Rust

1. clone the repo
2. do it
```bash
cd rust-cli-todo
```
3. start the program
```bash
cargo run
```
